#
install-apps-docker-desktop or docker or docker compose in Linux 
#
install docker desktop on your computer, you can download on the internet for windows and linux 
# 
install apps like nginx, apache2, phpmyadmin, prometheus, jenkins , grafana for monitoring and ubuntu server all using docker-compose file,
#
```bash
docker-compose up -d 

docker-compose down

docker create volume

docker volume ls

docker ps 

docker ps -a

docker volume inspect nginx_proxy

docker cp <container_id>:/var/jenkins_home ./jenkins-backup

docker start (container_id) or (container_name)

docker stop <container_id> or <container_name>

docker restart <container_id> or <container_name>
```
